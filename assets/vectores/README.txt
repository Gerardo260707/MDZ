Aquí debes pegar tus modelos vectoriales SVG para personalización.

Ruta recomendada:
- assets/vectores/

Ejemplo de archivo:
- assets/vectores/alcazar.svg
- assets/vectores/andros.svg

Importante para que se pinte por secciones:
- Cada sección del mosaico debe ser un elemento SVG independiente
  (path, polygon, rect, circle, ellipse).
- Opcional: agrega data-part="nombre-seccion" por pieza.
- El personalizador detecta y permite hacer clic en cada sección.
