# Favicon assets

Coloca aquí los íconos del sitio para la pestaña del navegador.

## Archivos recomendados

- `favicon.ico` (multiresolución clásica)
- `favicon.svg` (vectorial)
- `favicon-32x32.png`
- `apple-touch-icon.png` (180x180)

La app ya está configurada para intentar cargar estos archivos automáticamente desde `app.js`.
